# Keywords

Apple allows 100 characters, comma-separated, no spaces after commas. Do not repeat the app name. Do not include sexual terms.

```
discipline,habit,streak,check-in,constellation,routine,reset,focus,nights,self-control
```

That string is 86 characters.

“Abstinence” is an accurate description of the mechanic and it is not an explicit word, but it is also how adult-content apps are searched for. It is left out on purpose. Add it only if you want that search traffic and you have read Apple’s sexual-content rules for the listing.

Google Play has no keyword field. The English description in [listing-en.md](listing-en.md) already uses the words above.
