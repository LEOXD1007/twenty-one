# Store kit

Hosted pages and the answers to paste into App Store Connect and Play Console. The app itself does not load these pages.

| File | Use |
|---|---|
| [naming.md](naming.md) | English name options. **Twenty-One** is the one configured in the project. |
| [privacy-policy.html](privacy-policy.html) | The page to host. One URL covers English and Chinese. |
| [privacy-policy.md](privacy-policy.md) | The same text, for review in the repo. |
| [support.html](support.html) | A support URL Apple requires. Replace the email before you host it. |
| [app-privacy.md](app-privacy.md) | App Privacy “Data Not Collected”, and the Play Data safety form. |
| [age-rating.md](age-rating.md) | Apple age-rating answers and the Play content questionnaire. |
| [listing-en.md](listing-en.md) | English name, subtitle, description. |
| [listing-zh.md](listing-zh.md) | Simplified Chinese listing. |
| [keywords.md](keywords.md) | Apple’s 100-character keyword field. |
| [screenshots.md](screenshots.md) | What to capture, and at which sizes. |
| [pro.md](pro.md) | How to turn the one-time Pro unlock on later. Do not invent a price. |

Replace every `you@example.com` before you publish the hosted pages.
