# 简体中文商店文案

在 App Store Connect 和 Play Console 里新增简体中文（中国大陆）本地化后使用。应用内中文已经按系统语言切换，不需要商店页也能用。

| 字段 | 文案 |
|---|---|
| 名称 | 廿一 |
| 副标题 | 二十一天，二十一颗星 |
| 宣传文本 | 每天点亮一颗星。错过窗口，星空归零。 |

## 描述

```
二十一天。二十一颗星。

选定一个时刻。每天从这个时刻起，有三小时的窗口。长按，点亮一颗星。不能提前。窗口先关上，这一轮就结束，从第一天再来。已经走过的天数，会留在星图里。

二十一天都回来，星星连成一片星座。每颗星的位置，取决于你在窗口里的哪一刻按下。所以每一片星空都不一样。第二十一夜，应用会给你一张可以收下或分享的卡片。

星图保存完成的星座，也保存中断的记录。记录只在这台设备上。可以导出，也可以再导入。提醒由手机在窗口开启时、以及关闭前半小时安排。

看得见的一次重置。
```

## Google Play 简介（80 字以内）

```
二十一天，二十一颗星。每天一次的自律打卡。
```

商店文案用「自律」和「习惯」，不要用露骨的性描述。应用里的「破戒」是原来的界面用语，不要写进商店标题和副标题。
