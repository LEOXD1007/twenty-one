# English name

The Chinese name is 廿一. The home-screen wordmark stays 廿一 in both languages. The store and the English home-screen name need a Latin name.

## Use this one

**Twenty-One**

It is the direct name, it is short enough for a home screen, and it matches the 21 stars. This is the name already set as `CFBundleDisplayName`, `app_name`, and the Capacitor `appName`.

Subtitle (30 characters max): `21 days, 21 stars`

## Other names that would also work

Change these only before you create the App Store Connect record. Renaming a live app is possible but the bundle id is not.

| Name | Why it works | Why it wasn’t picked |
|---|---|---|
| **21 Nights** | Comes from the day-21 line, “twenty-one nights, and you came back.” | Reads slightly more like a story title than a tool. |
| **Twenty-One Stars** | Says what the picture is. | Long on a home screen, and “stars” is a crowded search word. |

Avoid names that mention sex, porn, or “nofap” in the title, subtitle, or keywords. The framing for both stores is a 21-day self-discipline and habit reset. The Chinese in-app word 破戒 stays in the Chinese UI because that is the original app. It is not used in the English store text.
